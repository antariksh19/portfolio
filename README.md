## 🚀 Overview

This repository contains the source code for my personal developer portfolio (v2). It goes beyond a simple frontend application by incorporating structured product documentation, a defined design system, and a clear development roadmap[cite: 4].

### 📂 Product Documentation
Unlike standard portfolios, this project is architected with product management principles. You can explore the engineering and design decisions in the `docs/` directory[cite: 4]:
* **[Product Requirements Document (PRD)](docs/portfolio-v2-prd.md):** The core requirements, user stories, and architectural scope[cite: 4].
* **[Design System](docs/design-system.md):** The typography, color palettes, and component guidelines ensuring UI consistency across the application[cite: 4].
* **[Roadmap](docs/roadmap.md):** Future feature implementations and optimization tracking[cite: 4].

## 🛠 System Setup

The project utilizes standard Node.js package management, incorporating customized PostCSS styling and strict ESLint configurations for code quality[cite: 4].

### Prerequisites
* Node.js (v18+)
* npm (Configured via the local `.npmrc` file[cite: 4])

### Local Development

**1. Clone the repository:**
```bash
git clone [https://github.com/antariksh19/portfolio.git](https://github.com/antariksh19/portfolio.git)
cd portfolio
```

**2. Install dependencies:**
```bash
npm install
```

**3. Run the development server:**
```bash
npm run dev
```

**4. Open your browser:**
Navigate to `http://localhost:5173` to view the application locally.

## 📦 Key Configurations

* `eslint.config.js` - Modern flat-config ESLint rules enforcing code quality and consistency[cite: 4].
* `postcss.config.js` - PostCSS configuration handling the CSS processing pipeline[cite: 4].
* `public/og-image.png` - Pre-configured Open Graph image for optimized social sharing previews[cite: 4].
* `public/profile.png` - Standardized profile asset used throughout the UI[cite: 4].
